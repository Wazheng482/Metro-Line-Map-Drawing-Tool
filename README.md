# 🚇 Metro Line Map Drawing Tool

一个功能强大的在线地铁线路图绘制工具。零依赖、零注册，开箱即用。

## ✨ 功能特性

### 核心工具
- **选择工具 (V)**：选择、拖拽站点，Shift 键约束 8 方向移动
- **站点工具 (S)**：点击画布放置站点，拖拽自动平移地图
- **线路工具 (L)**：从站点拖拽经过其他站点创建线路，拖拽回起点自动形成环线

### 线路类型
- **普通线路**：实线
- **高速铁路**：空心双线（外描边 + 内白芯）
- **虚线**：辅助线路、支线等

### 智能功能
- **自动换乘站**：被多条线路共用的站点自动变为换乘站，大小根据线路数量动态调整
- **自动环线**：拖拽回起点即可自动形成闭合环线，支持实时预览
- **圆角转角**：线路转角处自动添加微圆角，更符合真实地铁线路图
- **智能线宽**：普通线路 3px、高铁线 5px、选中时自动加粗

### 导出功能
- **SVG / PNG 导出**：支持 1x / 2x / 3x / 4x 分辨率
- **图例自定义**：可调节位置（四角）、颜色块自动匹配线路线型
- **图例语言**：支持中文 / 英文 / 双语显示，单语言时文字更大
- **报站音频**：自动生成语音播报

### 界面与交互
- **双语支持**：中文 / English 实时切换
- **三种主题**：白色 / 深蓝 / 黑色，一键切换
- **网格开关**：背景网格可开关，颜色自动适配主题
- **欢迎向导**：首次访问时引导选择语言、同意协议、设置主题、学习操作
- **实时颜色预览**：RGB 滑动条轨迹跟随当前颜色变化

### 其他
- **撤销 / 重做**：完整的操作历史记录
- **缩放 / 平移**：滚轮缩放、拖拽平移、按钮适应视图
- **数据本地存储**：所有数据保存在浏览器 localStorage 中

## 🚀 快速开始

无需安装任何依赖，直接打开 `index.html` 即可使用。

```bash
# 或者用 Python 启动本地服务器
python -m http.server 8000
```

## 🎯 使用流程

1. 点击 **站点工具**，在画布上点击创建站点
2. 点击 **线路工具**，从一个站点拖拽经过其他站点
3. 松开鼠标完成线路创建
4. 拖拽回起点 → 自动形成环线
5. 多个线路共用站点 → 自动变为换乘站
6. 选中元素，在左侧属性面板编辑名称、颜色、线型

## ⌨️ 快捷键

| 快捷键 | 功能 |
|:------:|------|
| `V` | 选择工具 |
| `S` | 站点工具 |
| `L` | 线路工具 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Y` | 重做 |
| `Shift+拖拽` | 站点 8 方向约束移动 |

## 🛠️ 技术栈

- **纯前端**：HTML5 / CSS3 / 原生 JavaScript
- **SVG 渲染**：矢量画布，支持无损缩放
- **自定义状态管理**：支持历史记录、撤销/重做
- **几何算法**：0°/45°/90° 角度约束路径生成、圆角贝塞尔曲线
