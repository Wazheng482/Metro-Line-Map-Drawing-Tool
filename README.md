# Metro Line Map Drawing Tool

一个在线地铁线路图绘制工具，支持创建站点、绘制线路（拖拽即可形成环线）、添加换乘站，并可导出图片和报站音频。

## 功能特性

- 🎯 **三种核心工具**：选择 / 站点 / 线路
- 🔄 **自动环线**：拖拽回起点即可自动形成闭合环线
- 🔀 **智能换乘**：被多条线路共用的站点自动变为换乘站
- 🌐 **双语支持**：所有内容支持中英文切换
- 🎨 **三种主题**：白色 / 深蓝 / 黑色
- 🖼️ **导出图片**：SVG / PNG 格式，可选分辨率和图例语言
- 🔊 **导出音频**：可录制报站提示音
- 🖱️ **交互操作**：拖拽连接、平移画布、缩放视图

## 使用方法

1. **选择站点工具 (S)**，点击画布创建站点
2. **选择线路工具 (L)**，从站点拖拽经过其他站点，松开完成
3. 拖拽回起点可创建环线，多站点共用即为换乘站
4. 点击站点或线路，在左侧属性面板编辑名称和颜色
5. 使用右上角导出按钮导出图片和音频

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| V | 选择工具 |
| S | 站点工具 |
| L | 线路工具 |
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |

## 技术栈

- HTML5 / CSS3 / 原生 JavaScript
- SVG 画布渲染
- 自定义状态管理（支持历史记录、撤销/重做）
- 0°/45°/90° 角度约束路径算法
