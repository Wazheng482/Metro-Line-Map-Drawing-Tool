地铁线路图绘制工具 (Metro Line Map Drawing Tool) 产品文档
============================================================

一、产品概述

地铁线路图绘制工具是一款基于 Electron 的桌面应用，使用原生 HTML/CSS/JavaScript
和 SVG 技术构建，无需任何前端框架依赖。用户可以在画布上创建地铁站点、连接线路、
编辑属性，并导出高清图片和报站音频。

该工具完全离线运行，所有数据仅存储在本地浏览器中，不上传任何用户数据。


二、功能清单

1. 主页与项目管理
   - 主页面采用 Word + VSCode 结合风格布局
   - 左侧边栏显示已保存的项目列表，按修改时间倒序排列
   - 每个项目显示名称、站点数、线路数和最后修改时间
   - 左上角可创建新项目或导入 MLMDT 项目文件
   - 点击项目可直接打开进入编辑器
   - 项目可删除，删除前有确认提示

2. 站点系统
   - 点击画布创建站点，自动编号（站点1、站点2...）
   - 站点默认英文名为 "Station 1"、"Station 2" 等
   - 支持中英文双语站点名称
   - 九种标签位置可选（左上、上、右上、左、中、右、左下、下、右下）
   - 多线路共用的站点自动识别为换乘站（白芯+外描边样式）
   - 站点可拖拽移动
   - 支持 Ctrl+C / Ctrl+V 复制粘贴站点

3. 线路系统
   - 线路工具：从站点按下拖拽，经过站点自动连接
   - 四种线路样式：
     * 普通线路（实线）
     * 高速铁路（双实线+虚线芯）
     * 空心线（透明填充+描边）
     * 虚线
   - 环线：拖拽回起点自动形成环线
   - 重新连接功能：可重新指定线路经过的站点序列
   - 线路颜色使用 RGB 三滑块选择器，支持 Hex 输入
   - 线路支持中英文名称

4. 文本系统
   - 文本工具：点击画布添加文本框
   - 七种中文字体可选（微软雅黑、宋体、楷体、仿宋、黑体、无衬线、衬线体）
   - 字体大小可调（10-48px）
   - 文本颜色使用 RGB 滑块选择器
   - 支持 Ctrl+C / Ctrl+V 复制粘贴文本

5. 视图控制
   - 滚轮缩放（0.25x - 4x）
   - 中键/Alt+左键平移画布
   - 适应视图按钮一键查看全部内容
   - 缩放百分比实时显示

6. 撤销/重做
   - 50步历史栈
   - Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做

7. 导出系统
   - 图片导出：
     * SVG 格式（矢量图，无损缩放）
     * PNG 格式（1x/2x/3x/4x 分辨率可选）
   - 图例：
     * 四角定位（左上/右上/左下/右下）
     * 中/英/双语可选
   - 报站音频导出：
     * 使用 meSpeak.js 离线语音合成引擎
     * 中文使用普通话语音，英文使用美式英语语音
     * 音频为 WAV 格式，自动打包为 ZIP 下载
     * 完全离线运行，无需联网
     * 生成后请等待20秒，如还未开始下载请重试
   - MLMDT 项目文件导出：
     * 包含所有站点、线路和文本数据
     * 仅可使用本工具的"导入项目"功能导入
     * 用于项目备份与迁移
   - 统一"开始下载"按钮触发所有选中的导出内容

8. 项目保存与加载
   - "保存至我的项目"按钮：将当前画布保存到本地存储
   - 返回主页时自动保存已打开项目的进度
   - 下次打开应用时从主页选择项目继续编辑

9. 设置
   - 三种主题：白色、深蓝、黑色
   - 网格显示开关
   - 中英文语言切换
   - 所有设置实时生效并持久化

10. 欢迎向导
    - 首次使用显示四步向导
    - 步骤一：选择语言（实时生效）
    - 步骤二：阅读并同意用户协议（全文展示）
    - 步骤三：选择主题（实时生效）
    - 步骤四：操作指南


三、快捷键

  V          选择工具
  S          站点工具
  L          线路工具
  Ctrl+C     复制选中的站点或文本
  Ctrl+V     粘贴已复制的站点或文本（偏移30px）
  Ctrl+Z     撤销
  Ctrl+Y     重做（或 Ctrl+Shift+Z）
  Delete     删除选中的元素
  Backspace  删除选中的元素
  Escape     取消当前操作，回到选择工具
  鼠标滚轮    缩放画布
  中键拖拽    平移画布
  Alt+左键   平移画布


四、技术架构

1. 文件结构
   index.html          页面结构、工具栏、模态窗口
   main.js             Electron 主进程
   preload.js          Electron 预加载脚本
   css/styles.css      全部样式
   js/state.js         全局状态管理（站点/线路/文本增删改、撤销重做、项目数据）
   js/canvas.js        SVG 画布渲染与鼠标交互
   js/properties.js    左侧属性面板
   js/export.js        图片/音频/MLMDT 导出
   js/toolbar.js       顶部工具按钮组
   js/settings.js      主题/语言/网格设置与 i18n 翻译
   js/welcome.js       欢迎向导
   js/home.js          主页与项目管理
   js/app.js           主入口、快捷键、视图切换
   js/geometry.js      几何计算工具
   vendor/mespeak/     meSpeak.js 语音合成引擎及语音数据

2. 状态管理
   - 使用发布-订阅模式（State.subscribe）
   - 历史栈最多 50 步，支持 undo/redo
   - 数据通过 localStorage 持久化

3. 语音合成
   - 使用 meSpeak.js 离线合成
   - 中文语音：zh.json
   - 英文语音：en/en-us.json
   - 音频数据以 ArrayBuffer 形式返回，转换为 Blob 后打包为 ZIP

4. MLMDT 文件格式
   {
     "format": "MLMDT",
     "version": "1.0",
     "name": "项目名称",
     "exported": "ISO时间戳",
     "data": {
       "stations": [...],
       "lines": [...],
       "textBlocks": [...]
     }
   }


五、隐私与安全

- 所有数据仅存储在本地浏览器的 localStorage 中
- 不收集、不上传任何用户数据
- 导出的图片和音频文件仅在设备上生成
- 禁用右键菜单
- 清除浏览器数据将导致项目丢失，建议定期导出 MLMDT 文件备份


六、适用场景

- 地铁爱好者绘制自定义线路图
- 城市规划展示与教学演示
- 交通系统可视化
- 创意设计与文化作品
